# Windows Downloads Flyout

A tiny utility to **avoid opening the downloads folder** every time.

## Why?

I was **very tired** of having to open the download folder every single time. There are programs, such as **Fences from Stardock** that do something similar, but I just needed a simple flyout, showing what's in the **downloads folder**.

## Functionalities
What can you expect from this tiny utility:

1. Right click **context menu**
2. Open in explorer button
3. Start with windows option
4. Light/Dark theme recognition

## How to install

1. **Copy** the content from the **/dist** folder to **any location** in your machine
2. Double click **DownloadsFlyout**
3. Open your **system tray**
4. Drag the **downloads icon** out and place it next to the system tray
5. Right click on the icon and click on **Start with windows**
6. Enjoy
